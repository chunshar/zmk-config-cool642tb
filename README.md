# 雑なメモ

### 2026/02/20
[DYA Studio](https://studio.dya.cormoran.works/) に対応させました。 \
USBまたはBluetooth接続でキーマップやトラボの設定をリアルタイムに実施できます。

- 初期のキーマップは万人向けではありません（右手小指でマウスレイヤ、KL同時押しでスクロールレイヤ等）
- Studio Unlockはデフォルトでレイヤ3（エンコーダーを1回押す）の左手最上段真ん中（E）にあります \
  レイヤ0に戻るにはもう一度エンコーダーを押してください
- トラックボールによるマウスとスクロールはStudioから設定しないと最初は使えません \
  初期のキーマップに合わせるなら
  - スクロールレイヤは2にすべし
  - オートマウスレイヤは4にすべし
- エンコーダは初期状態ではマウススクロールアップとダウンになっています \
  ただし、レイヤ1はボリュームアップ＆ダウン、レイヤ5は拡大鏡です
- コンボやタップダンスの設定はできないので、そこはkeymapファイルに直接書いてちょうだい
- バッテリー履歴表示機能は対応していません。そもそもバッテリーないし
- レイヤによるLED色変更機能も取り入れてあります
